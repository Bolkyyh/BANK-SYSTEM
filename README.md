BANK-SYSTEM



Description
The Simple Bank System is a beginner-friendly Python project that simulates basic banking operations through a console-based program. Users can check their balance, deposit money, and withdraw funds securely.

Features
- Check account balance
- Deposit money
- Withdraw money
- Prevents overdrawing
- Simple menu-driven interface

 Technologies Used
- Python

How to Run
1. Install Python on your computer
2. Download the project files
3. Open terminal or command prompt
4. Run the program using:

python bank_system.py

Sample Menu

=== Simple Bank System ===
1. Check Balance
2. Deposit
3. Withdraw
4. Exit

 Sample Output

Enter your choice: 2
Enter deposit amount: ₱500
₱500 deposited successfully.

Project Purpose
This project was created to practice Python programming concepts such as:
- Variables
- Conditional statements
- Loops
- User input handling
